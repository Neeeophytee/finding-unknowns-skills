## Project

Finding Unknowns turns overlooked assumptions into explicit decisions and evidence inside coding-agent workflows. The project maintains portable, single-file skills with focused triggers, practical examples, and documented installation checks.

The original eleven skills distill two essays by Thariq Shihipar with attribution and original instruction text. The local 1.4.0 candidate adds two maintainer-designed extensions for testing technical assumptions and finding behavior that passing tests miss. Those extensions have structural and discovery checks; independent behavioral comparisons are still pending.

## Original contribution

Our work is the instruction design, scope and evidence rules, cross-agent packaging, reproducible examples, compatibility checks, and maintenance. The methods build on published work; we distinguish the source ideas from our implementations and extensions.

## Hosting and credits

We intend to host an open-source documentation page and public evaluation reports in a dedicated Vercel project. Initial needs are static documentation delivery and preview deployments for changes. As evidence and demand grow, we plan interactive examples that let developers inspect how a skill changes a decision.

Credits would be used only for this OSS project. The commercial FlowStacks application would retain separate resources. No existing deployment, credit consumption, interactive playground, or benchmark infrastructure is claimed here.
