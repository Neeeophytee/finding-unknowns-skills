## Project

Finding Unknowns turns overlooked assumptions into explicit decisions and evidence inside coding-agent workflows. The project maintains portable, single-file skills with focused triggers, practical examples, and documented installation checks.

The original eleven skills distill two essays by Thariq Shihipar with attribution and original instruction text. Release 1.4.0 adds two maintainer-designed extensions for testing technical assumptions and finding behavior that passing tests miss. Those extensions have structural and discovery checks; independent behavioral comparisons are still pending.

## Original contribution

Our work is the instruction design, scope and evidence rules, cross-agent packaging, reproducible examples, compatibility checks, and maintenance. The methods build on published work; we distinguish the source ideas from our implementations and extensions.

## Refreshed application copy — September 9

### What distinguishes your project?

Finding Unknowns addresses a specific failure mode in AI-assisted development: an agent can confidently finish a task while missing the assumptions that make the result wrong. Its 13 portable, single-file skills cover blindspot discovery, requirements interviews, planning, context audits, assumption testing, and reviewing what passing tests miss. We document agent-specific compatibility and use CI to validate packaging and protect existing skills against unintended changes.

Since launching in July 2026, the repository has attracted 327 GitHub stars, 26 forks, and 1,000+ skill installs reported by skills.sh. Our saved GitHub traffic exports record 2,296 clones across 53 observed days between July 15 and September 7, including 528 in the latest exported 14-day window. The clone figures exclude estimates for missing dates and measure clone events, not unique users.
