FROM QUESTION TO EVIDENCE

Two small checks. Two different decisions.

These reproducible teaching fixtures demonstrate the workflow. They are not agent benchmark results.

01 / ASSUMPTION TEST

“Will retries create duplicate orders?”

The plan assumes one order per event ID. Deliver the same event twice to the local handler.

Expected: 1 order
Observed: 2 orders

Decision: Add idempotency to the plan before treating retries as safe. Concurrent delivery still needs its own check.

02 / TEST BLINDSPOTS

“What do our passing tests miss?”

The baseline passes. Try an administrator from tenant A against a document in tenant B.

Expected: access denied
Observed: access allowed

Decision: Preserve a tenant-boundary regression case before claiming the suite establishes isolation.
